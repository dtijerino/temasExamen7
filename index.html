Sección 2

Herramientas prácticas del navegador

Estas funciones ayudan a organizar información, regresar a páginas anteriores y trabajar con mayor rapidez.

Pestañas

Organizan varias páginas sin abrir muchas ventanas.

Historial

Permite revisar páginas visitadas anteriormente.

Marcadores

Guardan direcciones web importantes para consultarlas después.

Descargas

Muestran archivos que el usuario ha descargado desde Internet.

Buscar en página

Localiza una palabra dentro de un sitio largo. En muchos equipos se usa Ctrl + F.

Zoom

Aumenta o reduce el tamaño visual del contenido de la página.

Sección 3

Configuración del navegador

La configuración permite cambiar el comportamiento del navegador.

  • Elegir el buscador predeterminado.
  • Administrar privacidad y seguridad.
  • Revisar permisos de cámara, ubicación y notificaciones.
  • Administrar descargas e historial.
  • Modificar página de inicio y apariencia.

Extensiones, complementos y aplicaciones

E
Extensión
Agrega una función al navegador, por ejemplo bloquear publicidad, traducir o mejorar accesibilidad.
C
Complemento
Término general para componentes que amplían las funciones del navegador. En navegadores modernos suele usarse como sinónimo de extensión.
A
Aplicación web
Servicio que funciona desde el navegador, como correo, documentos en línea o herramientas educativas.
Cuidado
No se deben instalar extensiones desconocidas. Algunas pueden pedir permisos excesivos o recopilar información.
Sección 4

Navegación de incógnito

¿Qué es?

Es un modo de navegación que evita que el navegador guarde localmente parte de la actividad de esa sesión, como el historial de páginas visitadas.

¿Para qué sirve?

Puede ser útil cuando una computadora es compartida, cuando se quiere iniciar sesión temporalmente en otra cuenta o cuando no se desea conservar el historial local de esa sesión.

Importante: incógnito no significa “ser invisible en Internet”.

Sí hace

  • No guarda el historial local de navegación al cerrar la sesión privada.
  • Separa temporalmente cookies y sesiones del modo normal.

No hace

  • No oculta automáticamente la actividad al proveedor de Internet o a una red institucional.
  • No vuelve seguras páginas peligrosas.

Reto rápido

Un estudiante dice: “Si uso incógnito, nadie puede saber qué páginas visité”.

Sección 5

¿Qué es una URL?

Una URL es la dirección que identifica un recurso en la Web. Puede indicar el protocolo, el dominio y la ruta hasta una página concreta.

https://www.mep.go.cr/educacion
Haz clic en una parte de la URL para ver qué significa.

Partes principales

  • Protocolo: indica cómo se realiza la comunicación.
  • Dominio: identifica el sitio.
  • Ruta: señala una sección o recurso dentro del sitio.
Ejemplo
En https://www.mep.go.cr/educacion, el dominio principal es mep.go.cr.
Sección 6

¿Qué son los buscadores?

Un buscador es un servicio que ayuda a localizar información disponible en Internet. El usuario escribe palabras o una pregunta y el buscador muestra resultados relacionados.

No confundir
Chrome, Edge o Firefox son navegadores. Google Search, Bing o DuckDuckGo son motores de búsqueda.

Sección 7

¿Cómo funcionan los motores de búsqueda?

Para mostrar resultados útiles, los motores de búsqueda realizan varias etapas.

1

Rastreo

Programas automatizados recorren páginas y descubren nuevos enlaces y contenidos.

2

Indexación

La información encontrada se analiza y organiza en un índice para poder recuperarla rápidamente.

3

Consulta

El usuario escribe palabras clave o una pregunta.

4

Clasificación

El motor ordena resultados usando muchos factores para intentar mostrar primero los más útiles para esa consulta.

5

Resultados

Se presenta una lista de páginas, imágenes, videos u otros contenidos relacionados.

Recuerda
Estar en la primera posición no significa que una página sea automáticamente verdadera o la mejor para una tarea escolar.
Sección 8

Tipos de buscadores

Podemos distinguir buscadores generales y buscadores especializados.

Buscadores genéricos

Permiten buscar información sobre casi cualquier tema.

  • Google Search
  • Bing
  • DuckDuckGo

Ejemplo: buscar “qué es la fibra óptica”.

Buscadores específicos o especializados

Se concentran en un tipo de información o necesidad concreta.

  • Google Scholar: literatura académica.
  • Google Images: imágenes.
  • Google Maps: lugares y ubicaciones.
  • Buscadores internos de bibliotecas o sitios educativos.

Ejemplo: usar un buscador académico para encontrar artículos de investigación.
